# BikeRoutes.org Frontend

This directory contains the React + Vite frontend for [BikeRoutes.org](https://bikeroutes.org).

## Tech Stack
- **Framework:** React + Vite
- **Map Library:** MapLibre GL JS
- **Routing Integration:** Valhalla (via Cloudflare Workers proxy)
- **Styling:** Vanilla CSS (Tactical Hi-Tech theme)

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Run the development server:**
   ```bash
   npm run dev
   ```
3. **Build for production:**
   ```bash
   npm run build
   ```
