# Mascot Identity (Archived)

The Reki mascot identity guide has been retired. BikeRoutes.org now uses a neutral, practical brand voice and a bike-focused visual identity (cowboy-hat wordmark, bike logo, and clean vector marks) without a deer mascot.

This page is kept as a historical reference. For current brand guidance, see the [Style Guide & Conventions](./05_Style_Guide.md) and [Project Overview](./01_Project_Overview.md).
