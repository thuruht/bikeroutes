# BikeRoutes.org — Mascot Identity Guide

## Meet Reki 🦌

**Full name:** Reki
**Species:** White‑tailed deer (yearling buck)
**Pronouns:** He/him

### Name Etymology
| Origin | Meaning | Brand Connection |
|--------|---------|-----------------|
| Japanese (曆) | "Chronicle" / "History" | Every trail has a story — Reki remembers them all |
| Japanese (輝) | "Bright" | The deer who lights the way to the best trails |
| Military slang ("recce") | Scouting mission | Reki scouts the route before you ride it |
| Pop culture (SK8 ∞) | Energetic, youthful skater protagonist | Action‑sports culture crossover; appeals to the adventurous rider |

### Origin Story
> *Reki is the deer you see on every ride along the Kansas City trails — always one step ahead, always curious about what's around the next bend. He knows every shortcut through the woods, every creek crossing, every hidden overlook. Now he's sharing his knowledge with the world.*

### Personality Traits
- **Curious** — always exploring new trails and side paths
- **Adventurous** — prefers the off‑road shortcut over the paved main road
- **Friendly** — waves his white tail as a "follow me!" flag for other riders
- **Mischievous** — sometimes leads you on a longer, more scenic route on purpose
- **Community‑minded** — always looking back to make sure everyone's keeping up

### Visual Identity

#### Core Design Elements
| Element | Description |
|---------|-------------|
| **Build** | Young yearling buck — lean, athletic, not intimidating |
| **Antlers** | Small nubs or modest 4‑point rack — approachable, not aggressive |
| **Eyes** | Large, warm brown — expressive and friendly |
| **Chest** | Cream/white patch — distinctive at small sizes |
| **Tail** | Signature white flag, always held up — acts as a trail marker |
| **Cycling cap** | Forest green with cream brim, tilted slightly — casual, not try‑hard |
| **Messenger bag** | Olive/canvas with a small bike icon patch — carries trail maps |

#### Color Palette
| Swatch | Hex | Usage |
|--------|-----|-------|
| Deer Brown | `#C0763C` | Primary body color, warm headers |
| Blaze Orange | `#FF6B1A` | Primary accent, hunter safety aesthetic, UI highlights |
| Camo Olive | `#4B5320` | Secondary backgrounds, tactical UI surfaces |
| Cream White | `#FFF5E6` | Chest, tail, backgrounds |
| Forest Green | `#2D5F3A` | Cap, bag, accent buttons |
| Trail Tan | `#D4A96A` | Secondary backgrounds, card surfaces |
| Dark Hoof | `#0B0C08` | Text, outlines, deep tactical dark mode base |
| Sky Blue | `#6BAED6` | Links, interactive highlights, water features on map |

#### Logo Variations
| Variant | Use Case |
|---------|----------|
| **Full mascot** (standing pose with cap + bag) | Hero sections, about page, merch |
| **Head only** (cap + antlers + smile) | Favicon, app icon, small UI badges |
| **Silhouette** (side profile, tail up) | Watermark, loading animation, subtle branding |

## Reki's Voice (Copywriting Guide)

### Tone
- **Warm & encouraging** — never condescending
- **Slightly playful** — uses trail metaphors
- **Action‑oriented** — always suggesting what to do next

### Example Copy
| Context | Copy |
|---------|------|
| Welcome message | *"Hey! I'm Reki. I've scouted every trail in the Midwest so you don't have to. Let's ride."* |
| Error state | *"Whoa — Reki tripped on a root. Try again in a sec."* |
| Successful export | *"GPX downloaded! Reki'll meet you at the trailhead."* |
| Donation thanks | *"You're the best. Reki's doing a happy tail‑wag right now."* |
| No results | *"Hmm, Reki hasn't explored that area yet. Try a nearby region?"* |
